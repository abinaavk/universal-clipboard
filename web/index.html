Install on your devices

The browser app needs no install. For background sync on a computer or phone, add the uclip app (needs Node.js 20 or newer).

  1. Install Node.js 20+, and on Linux a clipboard tool: wl-clipboard (Wayland) or xclip (X11).
  2. Install uclip:
    curl -fsSL {{ORIGIN}}/install.sh | sh
  3. Sign in and approve the code in your browser:
    uclip login
  4. Start syncing:
    uclip daemon

Questions

Can you read my clipboard?

No. Everything you copy is encrypted on your device with a key that is derived from your password (or clipboard passphrase) and never sent to us. The server only stores ciphertext and cannot decrypt it.

What happens if I forget my password?

You can reset it by email, but because only your password can unlock your clipboard key, the old clipboard history is deleted on reset. Your account and devices keep working. Clipboard items expire after 7 days anyway.

Does it sync when I am signed out?

No. A device only reads or writes its clipboard while it has an active session. Sign out, revoke the device from the website, or let the session expire and syncing on that device stops immediately.

Which platforms are supported?

Windows, Linux (Wayland and X11), macOS and Android through the uclip command-line app, plus any modern browser and an installable Android web app.

What does it cost?

Nothing to try. This is a private deployment: sign-ups may be limited by the operator.

Can I use my own server?

Yes. The relay is a single dependency-free Node.js program with Docker and Caddy files included. Point the CLI at it with --server.
