HTTP API

Everything the website and the uclip app do goes through this API. Clipboard payloads are end-to-end encrypted by the client, so the API only ever carries ciphertext. The machine-readable spec is at /api/v1/openapi.json (OpenAPI 3.1).

Authentication. Devices send Authorization: Bearer uc_…. Browsers use the HttpOnly session cookie and add x-uc-csrf: 1 to non-GET requests. Passwords are never sent: clients send a derived authKey.
