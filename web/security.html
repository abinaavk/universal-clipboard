Security

Last updated 14 November 2026

How your clipboard is protected

  • End-to-end encryption. Each account has a random 256-bit vault key. Clipboard items are encrypted with it (AES-256-GCM) on your device before upload.
  • The server never sees your password or key. Your password is stretched on your device (PBKDF2-SHA-256, 310,000 rounds) into two independent halves: one proves who you are (the server stores only a salted scrypt hash of it), the other wraps your vault key. The server stores the wrapped key.
  • Google accounts have no password to derive from, so you choose a clipboard passphrase that wraps the vault key in the same way.
  • New devices receive the vault key sealed to a one-time key that only that device holds (ECDH P-256 plus AES-GCM). The approval step requires your password, and the server only relays the sealed blob.

Sessions

  • Every device has its own session. Browsers use an HttpOnly, SameSite=Strict cookie; apps use a bearer token. Only a hash of the token is stored.
  • Sessions end when you sign out, revoke the device in Settings, change your password or after 30 days without use. The device is disconnected immediately and the uclip daemon stops touching the clipboard and wipes its stored key.
  • Sign-in is rate limited per address and per account.

Website hardening

  • Strict Content-Security-Policy with no inline scripts or styles, HSTS, no framing, no referrer, locked-down permissions.
  • CSRF protection on cookie sessions (SameSite, a custom header and an origin check).
  • No third-party scripts, fonts or analytics.

What this does not protect against

  • A weak password. Choose a long one; anyone who steals the server data could try to guess it offline.
  • A compromised device. Anything you copy on it can be read by whoever controls it.
  • A malicious server operator serving modified web code. The command-line app avoids that by being installed from a file you can read.
  • Clipboard items are text only for now and are kept for 7 days.

Reporting a vulnerability

Email security@gaiasentinel.online. See also security.txt. Please give us a reasonable time to fix an issue before disclosing it.
